# React Phone Catalog

An interactive online catalog of mobile devices built with React, TypeScript and Vite.
The application allows users to browse products, view detailed information, add items to favorites and manage a shopping cart.

This project demonstrates modern frontend development practices including component-based architecture, routing, reusable UI components and responsive design.

## Features

- Browse phones, tablets and accessories
- Product details page
- Add products to cart
- Favorites system
- Pagination for catalog pages
- Responsive layout
- LocalStorage persistence
- Clean reusable component structure

## Technologies

- React
- TypeScript
- Vite
- React Router
- SCSS / CSS
- LocalStorage API

## Project Structure

```
src/
├─ components/     # reusable UI components
├─ pages/          # application pages
├─ store/          # state management (Zustand)
├─ utils/          # helper functions
├─ types/          # TypeScript types
├─ styles/         # global styles
└─ data/           # product data
```
## Getting Started

Install dependencies:

npm install

Run development server:

npm run dev

Build project:

npm run build

Preview production build:

npm run preview
